# THE NINTH SPICE™ — Modern Artisanal Storefront

A high-converting, modern artisanal direct-to-consumer (D2C) web application for **THE NINTH SPICE™** (Kundrapu Ventures Private Limited).

---

## 🌟 Key Features

1. **Brand Aesthetics & Modern Heritage**:
   - Palette inspired by raw unbleached parchment (`#FAF6EF`), Kashmiri Chilli Vermilion (`#C23321`), and Turmeric Gold (`#D98200`).
   - Editorial typography pairing Cinzel serif headings with clean Plus Jakarta Sans micro-copy.

2. **Core Science Differentiator — Low RPM Milling Simulator**:
   - Interactive comparison engine demonstrating the biological difference between commercial 3,000 RPM hammer milling (>80°C thermal loss) versus cold slow-milling (<32°C ambient, 100% volatile oil retention).

3. **Interactive Product Experience**:
   - Pack size selector (`150g`, `250g`, `500g`) with instant live price calculations.
   - Sensory gauges: Heat Level meter (Red Chilli) and Aroma & Curcumin Potency indicator (Turmeric).
   - "Lab Specs" modal with lab certifications, terroir origin, nutrition facts, and culinary pairings.

4. **Conversion-Optimized Cart & Indian Checkout Simulation**:
   - Slide-out cart drawer with dynamic **Free Delivery threshold progress bar** (Free shipping on orders > ₹599).
   - Quantity controls, item removal, and coupon code application (`WELCOME10` for 10% off).
   - Simulated Indian checkout flow supporting Instant UPI (GPay/PhonePe/Paytm), RuPay/Cards, NetBanking, and Cash on Delivery.

5. **Multi-Language Support**:
   - Instant language switching between **English**, **Telugu (తెలుగు)**, and **Hindi (हिंदी)**.

6. **Interactive Culinary Matcher & Recipes**:
   - 30-second cooking rhythm quiz recommending tailored spice packs.
   - Authentic traditional recipes (*Andhra Guntur Kodi Vepudu*, *Heritage Golden Haldi Latte*, *Guntur Tomato Pappu*) with one-click "Add Recipe Spices" action.

7. **Brand Transparency & Customer Care**:
   - Interactive modals for **Our Heritage Story** and **Customer Support Form**.
   - Transparent corporate disclosure: Kundrapu Ventures Private Limited, Paravada, Visakhapatnam, AP.
   - Direct helpline: `+91 9441413344`, Email: `support@theninthspice.com`.

## 🚀 Running the Project

```bash
# 1. Install dependencies
npm install

# 2. Start the development server
npm run dev

# 3. Build for production
npm run build

# 4. Preview production build
npm run preview
```

Currently running live at: **http://localhost:5173/**
